# Movie-Rating-Analysis
Movie Rating Analysis using Python is a Data Science project that analyzes movie ratings, identifies top-rated and most-rated movies, compares genre-wise ratings, and explores user rating patterns using Pandas, NumPy, Matplotlib, and Seaborn. Developed as part of the CODTECH Solutions Data Science Internship.
# Movie Rating Analysis Using Python

## 5. Dataset Description

This project uses the MovieLens Latest Small dataset provided by GroupLens Research.

The dataset contains movie information and user ratings.

The project uses two main files:

* `movies.csv` — Contains movie IDs, movie titles, and genres.
* `ratings.csv` — Contains user IDs, movie IDs, ratings, and timestamps.

**Dataset Source:** https://grouplens.org/datasets/movielens/latest/

## 7. Key Analysis Performed

### Movie Rating Distribution

Analyzes how frequently different rating values occur in the dataset.

### Top-Rated Movies

Identifies highly rated movies using average ratings while applying a minimum rating-count requirement.

### Most-Rated Movies

Finds movies that have received the greatest number of user ratings.

### Genre-Wise Analysis

Compares average ratings across different movie genres.

### Release-Year Analysis

Explores how average movie ratings vary by release year when year information is available.

### User Rating Activity

Examines the number of ratings submitted by individual users.
